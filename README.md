# 📄 Synthèse Complète - Droit Administratif (LDROI1305)

Synthèse complète et détaillée du cours de Droit Administratif de l'UCLouvain basée sur les notes de Victoria Oblin (2024-2025).

## 📋 Contenu du PDF

Le PDF généré contient :

- ✅ **Introduction** : Définitions fondamentales et lois de Rolland
- ✅ **Partie 1** : Organisation externe de l'administration
- ✅ **Partie 2** : Organisation interne (fonction publique)
- ✅ **Partie 3** : L'acte administratif unilatéral (AAU)
- ✅ **Partie 4** : L'acte administratif bilatéral (contrats)
- ✅ **Partie 5** : Le contrôle de l'administration
- ✅ **Fiches récapitulatives** : Questions phares d'examen
- ✅ **Lexique** : Termes essentiels en ordre alphabétique

## 🚀 Installation et utilisation

### Prérequis
- Python 3.7 ou supérieur
- pip (gestionnaire de paquets Python)

### Étapes

1. **Cloner le repository** :
```bash
git clone https://github.com/p24dfb4vfw-design/Amer.git
cd Amer
```

2. **Installer les dépendances** :
```bash
pip install -r requirements.txt
```

3. **Générer le PDF** :
```bash
python build_synthese_complete.py
```

4. **Résultat** :
Le fichier `Synthese_DA_COMPLETE_BAC3.pdf` est créé dans le répertoire courant.

## 📚 Structure du code

- `build_synthese_complete.py` : Script principal qui génère le PDF
